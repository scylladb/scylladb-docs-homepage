===============================
ScyllaDB DynamoDB Drivers
===============================

ScyllaDB AWS DynamoDB Compatible API can be used with any AWS DynamoDB Driver.

For a list of AWS DynamoDB drivers, see
`Getting started with DynamoDB <https://docs.aws.amazon.com/amazondynamodb/latest/developerguide/GettingStarted.html>`_
in the Amazon DynamoDB documentation.
