# Troubleshooting ScyllaDB

ScyllaDB’s troubleshooting section contains articles which are targeted to pinpoint and answer problems with ScyllaDB. For broader issues and workarounds, consult the [Knowledge base](https://docs.scylladb.com/manual/branch-2025.4/kb/index.md).
Keep your versions up-to-date. The two latest versions are supported. Also, always install the latest patches for your version.
